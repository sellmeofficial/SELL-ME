# SELL ME

## About

SELL ME is a digital marketplace designed for Eswatini where people can:

- Buy and sell products
- Discover local businesses
- Find student deals
- Access local services

## Current Features

- Home Page
- Marketplace
- Login
- Register
- Seller Dashboard
- Add Product
- Shopping Cart
- Product Page

## Technologies

- HTML5
- CSS3
- Bootstrap 5
- JavaScript

## Future Features

- User Accounts
- Product Upload
- Live Chat
- Mobile App
- Payments
- Delivery Tracking
